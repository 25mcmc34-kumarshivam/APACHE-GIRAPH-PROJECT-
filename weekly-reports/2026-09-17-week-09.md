## Text versus JSON conclusion

JSON is text, but Giraph does not select a parser from the filename extension.
The class supplied through `-vif` defines the record format. The previous JSON
reader accepts JSON arrays. The new text reader accepts a simpler weighted
adjacency-list syntax. The graph algorithms do not require changes when both
readers produce the same vertex, value, and edge types.
