# Week 15 — 23–29 October 2026 (work recorded by 26 October)

This week we made the **standard, input-driven Graph Burning** experiment easier to inspect. We did not search for the best ignition sequence. The user supplies a graph and its source rounds; Python predicts the state after every round, and the saved Giraph result provides an independent comparison of the final state. This is separate from Week 14's source-only, limited-neighbour teaching experiment.

## What we used and made

- Reused the nine-node path split into three text files in [`datasets/graph-burning-path-9-scheduled/`](../datasets/graph-burning-path-9-scheduled/). Its chosen sources are 3 in round 1, 8 in round 2, and 6 in round 3. The choice is hand-written, not optimized.
- Used [`scripts/validate_burning_schedule.py`](../scripts/validate_burning_schedule.py) to parse and validate the input and to calculate an independent shortest-hop prediction. No source is chosen by that program.
- Added and ran [`scripts/show_burning_rounds.py`](../scripts/show_burning_rounds.py). It simulates the one-edge-per-round fire spread, prints newly burned, cumulatively burned and unburned vertices, and writes `expected.tsv` plus per-round vertex/edge tables. With optional NetworkX and Matplotlib it also writes a GraphML burned subgraph and a PNG of the full graph after each round.
- Added [`tests/test_show_burning_rounds.py`](../tests/test_show_burning_rounds.py). On the development PC, the full Python test suite passed (33 tests). The lab PC run of the preview succeeded.
- Installed NetworkX 3.4.2 and Matplotlib 3.10.9 with `python3 -m pip install --user networkx matplotlib` for the `mca2025` account. These packages are for visualization; they are not Hadoop/Giraph dependencies.

The Hadoop services were running under `hduser`; `yarn node -list` showed one RUNNING node. As `mca2025`, we copied the previously uploaded HDFS input directory to a new local temporary folder and ran the preview with `--networkx --png`. The round states were:

We did **not** submit a new Giraph job this week for this comparison. The per-round pictures, GraphML subgraphs, vertex/edge tables and `expected.tsv` are saved in [`results/graph-burning-path-9-scheduled/round-preview/`](../results/graph-burning-path-9-scheduled/round-preview/).
