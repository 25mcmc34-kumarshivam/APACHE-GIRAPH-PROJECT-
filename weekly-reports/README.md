# Weekly Reports

The [master weekly timeline](../docs/WEEKLY-TIMELINE.md) begins on 17 July 2026. Use the [weekly report template](../docs/WEEKLY-REPORT-TEMPLATE.md) for each Thursday meeting.

Recommended filename format:

```text
YYYY-MM-DD-week-N-group-shared.md
YYYY-MM-DD-week-N-group-a.md
YYYY-MM-DD-week-N-group-b.md
```

Each report must contain:

- planned goal;
- concepts studied;
- completed work;
- Git commits, commands, datasets, and results;
- errors, causes, and verified fixes;
- individual contributions;
- supervisor feedback;
- assigned work for the next Thursday.

Earlier weeks with missing evidence must remain marked `Record needed` until reliable notes are recovered.
